# Council contribution rules

Read and follow `AGENTS.md`; it is the shared contribution contract. Read `council/protocol.md` for the decision workflow. In mixed councils Codex remains lead/chair; Claude supplies independently scoped disconfirmation/auditing. Do not bypass Claude's nested-session safeguard or use API credentials as a substitute for the requested subscription workflow. The native `/council` skill can use actual independent host subagents, with explicit disclosure that the CLI's hard enforcement does not apply.
